# AlsinaOperations

Aplicación web estática que permite sumar dos números.

## Uso local

Abre `index.html` en un navegador, o sirve la carpeta con cualquier servidor estático:

​```bash
python3 -m http.server 8000
​```

Luego visita `http://localhost:8000`.

## Despliegue

No requiere backend ni build. Puede desplegarse directamente en GitHub Pages, Netlify o Vercel apuntando a la raíz del repositorio.
